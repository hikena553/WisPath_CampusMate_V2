学生页 UI 重设计 · 三选一

学生页：从「平铺名单」到「该先找谁」

现有界面是搜索 + 五个危机筛选项 + 一列等高的学生卡，问题不在于难看，而在于它只回答了「我有哪些学生」，没回答「我现在该找谁」。 下面三套都是可以真正点开操作的——搜索会过滤、筛选会生效、点学生会拉出详情抽屉。先玩一遍再选。

可以试的操作： 搜索框输入「林」 切换筛选点高危 / 点列头排序 点学生拉出详情抽屉 数据与真实后端字段一致（crisis_level / score / growth_count）

我的建议：A 为主，B 作为 A 的「全部」页

你的教师端定位是「育人 + 辅导员工作台 + 个人工作台」，三者里辅导员工作台最需要一个「现在是哪个学生出事了」的入口。 A 和「今日重点」是同一种语言（待办队列），用户不用切换心智；而 B 的价值在「全部 42 人」这个场景下才成立。 所以最省事的做法是：默认 A 的分诊视图，切到「全部」时自动降级成 B 的数据表——一套页面两种密度，比三选一更实用。
