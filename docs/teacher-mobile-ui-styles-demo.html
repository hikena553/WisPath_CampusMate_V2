功能子页

怎么选

三套共用同一套信息骨架和同一份数据，换样式只换 CSS 变量与容器形态 —— 也可以按页混用。

A · Clarity默认推荐

清爽白 + AI 前置。每页第一块就是 AI 结论，列表单列、行高 60 上下，一屏 4 条。

适合
日常高频使用，一盯一整天；老师要的是「结论先给我」
代价
视觉最常规，和市面工具同质化；AI 存在感靠紫色卡撑
留给
全部 13 页的默认皮肤
B · Paper有人情味

暖纸底 + 衬线标题 + 双列卡片，AI 变成贴在页面上的便签，点开才展开提纲。

适合
育人 / 关怀 / 家校这类要「像老师写的」的页面
代价
双列密度低 15%，长姓名会挤；深色模式需另做一版
留给
关怀中心 · 成长档案 · 家校沟通
C · Console高压工作台

深色 + 等宽数字 + 左侧状态条，一屏 6–8 条；AI 缩成一行紫色指令条。

适合
盯预警、批量审批这种「要在 30 秒内扫完」的场景
代价
白天户外可读性差；深色下红绿对比要重调
留给
预警 · 审批（也可只做夜间模式）
混用建议 A 打底 → 预警 / 审批换成 C → 关怀 / 档案 / 家校换成 B。共用骨架意味着换皮成本约等于一份 CSS 变量，不需要重写页面结构。 点左侧页面切页三套并排对比点样式卡放大
