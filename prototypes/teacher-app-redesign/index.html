「常用功能」子页面 & 弹窗 重构

手机容器内为可交互原型，直接点击「首页 → 常用功能宫格 / 全部功能」即可进入各功能子页面并唤起弹窗。

① 九个功能，九套专属版式
  • 审批：待办优先顶条 + 审批票据卡（内嵌审批流时间轴 / 附件 / SLA）+ 底部常驻审批条。
  • 预警：风险分布环 + 24 小时 SLA 倒计时 + 等级色带卡 + 处置步骤条。
  • 公告：触达率进度 + 公告卡（置顶 / 紧急角标）+ 已读统计。
  • 成长档案：学生横向选择器 + 成长时间轴 + 徽章墙。
  • 问卷互评：回收率环形进度 + 匿名保护标识 + 维度标签。
  • 关怀中心：关怀温度条 + 待回访提醒 + 谈心 / 家访 / 激励时间轴。
  • 家校沟通：家长联系人卡（通话 / 短信 / 微信）+ 沟通台账时间轴。
  • 今日任务：完成度进度 + 今日 / 逾期 / 本周分段 + 可勾选清单。
  • AI 洞察：AI 建议卡（置信度）+ 洞察指标 + 一键行动。
② 弹窗：底部弹窗体系（统一样式）

每个功能均配套弹窗：顶部 20px 圆角 + 抓手条 + 页头 + 可滚动内容 + 常驻主按钮的 底部弹窗（ActionSheet 范式）。表单一律「白底列表行 + 分段选择 chips + 附件行」，与钉钉 / 飞书发起流程一致。

③ 尺寸与图标色调统一

组件尺寸整体上调（底部导航 58px、宫格图标块 52px、列表图标块 40px、按钮最小高度 42px）；图标块统一为「soft 底 + 深色前景 + 发丝内描边」，色值仅取 6 个签名色，禁用 Element 默认散色。

品牌 #2563eb 成功 #079455 警告 #b54708 危险 #d92d20 紫 #6941c6 青 #0891b2
④ 采用开源成熟体系

Lucide（ISC）图标库 —— 122 枚图标全部取自官方 sprite 的真实 path，内联 SVG、离线可用；Untitled UI 开源设计系统色板 / 圆角 / 灰阶令牌；Ant Design Mobile 交互范式（Popup / ActionSheet / Steps / Timeline / Progress / Empty）。
