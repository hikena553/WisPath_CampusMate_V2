「更多」→ 消息中心 重构

手机容器内为可交互原型，直接点击即可体验。本页改动为信息架构级调整，请重点确认下列三点。

① 底部导航：更多 → 消息
首页学生绵小城消息个人中心

原「更多」页签改名为「消息」，定位为钉钉式消息中心；原「更多」内其余功能全部迁至首页。

② 消息中心 = 消息 / 通讯录 / 通知
  • 消息：默认主视图。置顶会话 + 单聊/群聊列表（左滑置顶/免打扰），点击进入会话。
  • 侧边抽屉：左上角菜单唤出，内含 消息 / 通讯录 / 通知 三项导航，通讯录与通知不再与消息抢主视图位置。
  • 通讯录：全校师生检索（姓名/学号/工号）+ 我的学生 + 组织架构树（学院 → 专业 → 班级）。
  • 通知：审批 / 预警 / 公告 / 反馈 / 系统，点击直达对应子页面。
  • 会话内：文字 / 图片 / 文件 / 语音附件面板；群聊含群公告、群成员、群文件、群设置。

组织架构来自管理端「院系班级」配置（College → Major → ClassGroup），与后端 Notification / Message / Group 三套模型打通。

③ 其他功能迁至首页（彩色圆角宫格）

首页新增「常用功能」宫格：审批 / 预警 / 公告 / 成长档案 / 问卷互评 / 关怀中心 / 家校沟通，一行平铺、超出可左右滑动，带实时角标，点击进入子页面。首页保持简短概览定位。

④ 子页面配色统一规范

所有子页面统一为：吸顶 AppBar + 语义化指标卡 + 分段筛选 + 白卡列表；配色仅取自设计令牌，禁用 Element Plus 默认散色。

品牌 #2563eb 成功 #079455 警告 #b54708 危险 #d92d20 紫 #6941c6 青 #0891b2
⑤ 弹窗：钉钉式流程

移动端不做居中弹窗，改为整页流程（吸顶页头 + 常驻确定条 + 白底列表行）；桌面端保留居中弹窗但共用同一套皮肤：52px 页头、发丝线、圆角 14px、仅一个品牌色主按钮，次要按钮用中性填充。选择联系人统一为「搜索 + 白底列表 + 选中态」，与钉钉发起单聊/群聊一致。

⑥ 全部功能子页面

首页「常用功能」卡片右上角提供全部功能入口，下钻到功能总览子页（分段分组 + 彩色圆角图标行 + 搜索 + 实时角标）。该页只列底部页签之外的模块，避免与 首页/学生/绵小城/消息/个人中心 重复。
