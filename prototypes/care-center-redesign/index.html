OPTION A

档案纸页

把「关怀」当成一份持续书写的学生档案：日期、编号、细线、衬线标题。
质感最稳 · 落地最快

为什么这样改

当前首页已经是列表，但「概览数字 / 工作台 / 动态」缺少视觉层级。A 用报纸式的眉批、编号和细线，把三者变成可扫读的档案目录，重点一眼可见。

关键结构

  • 数字表代替统计卡片，四列一屏读完
  • 工作台用 01–05 编号，形成「目录」心智
  • 家校台账按日期分组，左栏是日期、右栏是事实
  • 学生聚焦用竖线时间轴，事实与动作同列

适合与代价

适合：想要安静、专业、可打印/可导出的档案感；改造成本最低。

代价：信息密度偏高；图表能力弱，关怀看板仍要单独设计。

OPTION B

行动台

从「看数据」改为「处理事情」：首页先给今天要做的三件事，再给记录入口。
最推荐 · 闭环最快

为什么这样改

合并后的首页入口很多，老师真正需要的是「现在该做什么」。B 把待办前置为三行任务，每条都带下一步动作，处理完直接归档；统计退到第二屏。

关键结构

  • 首页第一屏只放 3 件紧急事 + 一个主操作
  • 任务行左侧细色条区分紧急度，不用整块卡片
  • 家校台账每条记录都带「下一步」与截止日
  • 学生聚焦先给建议动作，再给轨迹

适合与代价

适合：每天高频处理待办、追求闭环速度的辅导员。

代价：引入琥珀色提醒；首页更像「工作台」，档案感弱于 A。

OPTION C

关系地图

把学生放在圆心：家长、任课老师、心理老师与关怀动作，构成一张可读的支持网络。
最有辨识度 · 关系洞察

为什么这样改

C 把「家校沟通」从一张台账升级成一张关系网：谁是主要联系人、谁最近被联系过、支持网络是否完整。它最适合回答「这个学生身边有谁」。

关键结构

  • 首页以学生为圆心，四个关键关系节点
  • 30 天温度格子，替代传统折线图
  • 联系人按关系排列，右侧点阵显示最近联络频率
  • 聚焦页用支持网络完整度驱动下一步

适合与代价

适合：强调家校关系、需要快速看清支持网络的场景。

代价：关系图占空间；需要联系人数据较完整，否则画面会空。

怎么选

我的建议：首页用 B（行动台）把待办和记录入口前置，家校沟通用 A（账簿）保留日期分组的档案感，学生聚焦用 C（关系地图 + 时间轴）突出支持网络。这样既不堆卡片，也能把「发现 → 处理 → 留痕 → 回看」串成一条线。
