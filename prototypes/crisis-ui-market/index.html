三套的差别，用一句话说清

都是市面上真实存在的产品结构，只是密度和重心不同。选哪套，取决于老师每天打开这个页面时最想先看到什么。

维度1 · 飞书风格2 · 钉钉风格3 · Apple 原生
核心页面一张预警表格工作台 + 待办个案三栏 / 分组列表
老师第一眼49 条预警的全貌与筛选今天要处理哪几件事这个学生发生了什么
信息密度最高中高最低
学习成本低（用过飞书几乎零成本）低（和现有工作台一致）中（需要重做一套组件）
与现有产品一致性中（需引入飞书蓝与表格规范）高（项目已有钉钉式模块）低（原生系统语言差异明显）
移动端列表 + 状态页签深墨头部 + 浮层 + 宫格 + 页签大标题 + 分组列表
适用场景桌面批量处置为主桌面 + 移动日常办公深谈与个案跟进
已选方向：2 · 钉钉风格，移动端头部由品牌蓝改为项目深墨色（#1E2227）。蓝色只保留在链接与选中态这类小面积元素，大面积色块全部交给黑白灰，红色仅用于高危与逾期这类风险语义。
桌面端为「工作台 + 今日待办 + 预警动态 + 预警清单」，移动端为「深墨头部 + 白色浮层 + 宫格入口 + 底部页签」。全部现有能力均已落位：指标总览、等级 / 状态筛选、随访时限与逾期、清单分页、干预登记、标记闭环、跳转学生档案、学生 / 预警深链、移动端二级页与下拉刷新。
说明：以上为设计参考稿，不含真实学生数据；所有姓名与记录均为示例。参考产品结构：飞书多维表格 / 审批、钉钉工作台与宫格组件、Apple Human Interface Guidelines（分栏、分组列表、44pt 行高）。
