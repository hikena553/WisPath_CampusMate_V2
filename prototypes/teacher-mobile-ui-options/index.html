教师移动端 UI 设计方案

基于现有设计契约（Untitled UI 色板 · Lucide 图标 · Ant Design Mobile 范式）延展的四个页面重构方案： ① 任务清单 ② 学生详情 ③ 学生表单展示 ④ 学生主页。每个页面提供 2~3 个可选方向，点击「方案 A / B / C」切换预览。

① 任务清单

签名色 success ·「今日任务」模块重构

三个方向解决同一个问题：让辅导员在 3 秒内知道「现在该干什么、什么快逾期了」。A 重执行效率，B 重全局盘点，C 重时间节奏。

方案 A · 勾选清单式 推荐

  • 环形完成度 + 今日/逾期/本周分段，先给全局再给清单
  • 任务即勾选行：圆形 checkbox、优先级色签、关联学生头像内联展示
  • 完成划线置灰，正向反馈即时；单手可达，滑动可完成
适合：日常高频打卡型使用（每天打开 5~10 次）。参考：滴答清单 / iOS 提醒事项。

② 学生详情

教师端「学生」页下钻 · 同一设计逻辑延展

沿用任务清单的设计逻辑：先给「全局状态」（头卡/指标），再按需下钻明细。三个方向决定「以什么为骨架组织学生信息」。

方案 A · 档案头卡 + 锚点 Tab 推荐

  • 渐变头卡承载身份（头像/班级/标签），KPI 行给出三关键数
  • 锚点 Tab（概览/课业/考勤/档案）组织多维度信息，与任务清单「分段器」同一交互范式
  • 风险卡置顶：SLA 倒计时条与预警处置强绑定，可直接跳转任务
适合：信息维度多、需长期跟进的重点学生。与方案①A 搭配最统一。

③ 学生表单展示

查看学生提交的表单（请假 / 申请 / 问卷）· 同一设计逻辑延展

延续「先全局、后明细」逻辑：表单不是一屏字段堆砌，而是「状态 → 摘要 → 明细 → 流转」的阅读动线。

方案 A · 票据卡 + 审批流 推荐

  • 顶部状态横幅（色块 + 图标）先给结论：审核中 / 已通过 / 已驳回
  • 票据卡按「基本信息 → 申请内容 → 附件」分组，label-value 行式排版高密度可读
  • 底部审批流时间轴 + 常驻操作条（驳回 / 通过），审批闭环不跳页
适合：请假、奖学金、证明开具等带审批流的表单。与设计契约的 approval 弹窗同一范式。

④ 学生主页

教师点击查看学生主页 · 同一设计逻辑延展

「学生主页」是学生视角的展示面（区别于②的工作台视角）：先看这个人是谁、状态如何，再看动态与档案。

方案 A · 个人空间式 推荐

  • 封面 + 头像 + 格言的「个人空间」头部，弱工作感、强人物感
  • 徽章墙横滑（荣誉/技能/参与），与成长档案模块的徽章体系打通
  • 数据带 + 动态流：教师可点赞互动，主页成为师生轻互动触点
适合：学生端已有个人主页产品、教师以「拜访」视角查看。参考：微信状态 / 校园社交 App。

推荐组合与落地说明

页面推荐方案核心交互范式说明
任务清单 A 勾选清单式 环形进度 + 分段器 + 可勾选行 与设计契约中「今日任务」签名版式（完成度进度 + 今日/逾期/本周分段 + 可勾选清单）完全一致，属契约内方案的深化。B/C 可作为「任务中心」二级视图保留。
学生详情 A 档案头卡 + 锚点 Tab 渐变头卡 + KPI 行 + 锚点分段 + 风险卡置顶 沿用「先全局后明细」逻辑；风险卡 SLA 条与任务模块联动（一键生成首谈任务）。
学生表单 A 票据卡 + 审批流 状态横幅 + 分组票据卡 + 审批流时间轴 + 常驻操作条 复用契约中 approval「审批票据卡 + 审批流时间轴」与底部弹窗操作条范式；B 方案用于长表单。
学生主页 A 个人空间式 封面头像 + 徽章墙横滑 + 数据带 + 动态流 与成长档案（violet 签名色）徽章体系打通；B 方案可作教师端「档案视图」切换项。

统一设计语言：四组方案共享同一套令牌（#2563eb 主色 / 6 签名色系 / 10~22px 圆角 / 毛玻璃底栏 / Lucide 图标）、 同一条信息动线「状态总览 → 关键指标 → 明细内容 → 操作闭环」，以及同一组件词汇表（分段器、chips、色签、时间轴、常驻底栏）， 因此四个页面可自由混搭（如任务用 A、表单用 B）而风格不割裂。
