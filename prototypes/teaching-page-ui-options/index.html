方案 A

液态玻璃 视觉最出挑

抄自：iOS 26 Liquid Glass、visionOS 卡片
  • 半透明毛玻璃 + 双层高光描边，底色是蓝紫极光渐变
  • 44px 超大数字做锚点，状态收成一排玻璃胶囊
  • 导航栏只留返回 / 更多，页面内用 31px 大标题
  • 圆角 20–26px，分隔靠透明白线而非硬描边
适合：想强化「新」「高级」感，iOS 用户零学习成本。
代价：多层模糊对低端安卓有性能开销；玻璃上 11px 文字对比度偏低；与现有 tui 白卡风格差异最大，其他页面会显旧。

方案 B

效率蓝 推荐

抄自：飞书 / 钉钉 / 企业微信移动端
  • 纯白卡片 + 极浅投影，蓝色只出现在操作与选中态
  • 概览左数字右 2×2 指标格，异常项浅橙 / 浅红底
  • 两个下拉压成「标签—值—箭头」两行，首屏少占 90px
  • 分段控件用实心蓝胶囊，选中态一眼可见
适合：与现有 teacher-mobile-kit 的白卡 / 蓝主色同源，改造成本最低，老师无学习成本。
代价：记忆点偏弱，容易「像后台系统」；11–13px 字号密集，需要靠留白撑住呼吸感。

方案 C

暖橙活力 最亲和

抄自：小红书首页卡片、抖音生活服务、美团
  • 珊瑚渐变主卡 + 奶油底色，首屏情绪最足

方案 D

Notion 极简 最耐看

抄自：Notion / Linear / Arc 的列表与排版
  • 取消卡片，用发丝分割线分组，靠排版而不是阴影
  • 52px 数字 + 指标改成 label / value 列表行
  • 全页只有靛蓝 #5B5BD6 一个强调色，只出现在选中下划线
  • 18px 左右留白，字号 10.5–13.5px，信息密度最高
适合：熟练用户、后续还要持续加模块，底子最干净。
代价：气质偏冷，缺少教学氛围；0 值列表扫读不如彩色胶囊快；要替换现有白卡组件，改动量最大。

怎么选：我建议先上 B

B 效率蓝和现有 teacher-mobile-kit 同源（白卡、蓝主色、12–14px 字号），只需要重排信息：两个下拉改成两行、概览改 2×2 指标格、分段控件做实心蓝选中，样式 token 基本复用，回归风险最小。
A 最出挑，但每张卡都要加毛玻璃层，低端安卓有性能与对比度风险；C 适合家长端联动，放在教师端会和校内其他页面割裂；D 最耐看，但要替换列表组件，工作量和波及面最大。
如果舍不得 A 的观感，可以取「B 骨架 + A 的顶部极光渐变」，只多一条顶部渐变背景，不动卡片结构。
