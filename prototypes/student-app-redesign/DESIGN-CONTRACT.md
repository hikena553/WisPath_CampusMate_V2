# Design Contract — 学生端移动「驾驶舱」重构 · v2

> v2 修订动因：第一版评审两点否决——①主页「更多」做成 6 个彩色图标方块，像 PC 工具箱，不像移动 App；②大面积蓝色（Hero 渐变 + 5 条彩色进度条 + 15 处 brand 色），不符合要求。
> v2 的做法不是调色，而是**换一套色彩哲学**：从「一屏多色块」改为「中性灰打底 + 只给状态上色」。

## 0. 意图

rewrite（`prototypes/student-app-redesign/`，不动教师端原型）。

目标：把学生端移动驾驶舱（`/student/schedule` 移动态）从「一屏堆砌」改为**分层的移动产品结构**：
**主页只放「今天该做什么」与「我现在怎么样」**，所有需要展开/回溯/解读的内容一律下钻到二级页。

硬约束：
- 功能零删减（原有一切入口、数据、动作都必须在某个层级可达）。
- 不做视觉炫技，克制、朴素、耐看。
- 技术栈：vanilla HTML/CSS/JS · pure-static（`file://` 双击可开、零外部依赖、可离线评审）。

## 1. 采用的开源成熟体系

| 来源 | 许可 | 采用部分 |
|---|---|---|
| **Lucide** | ISC | 全部图标，官方 path，内联 `<symbol>` sprite，122 枚，统一 `stroke-width: 1.75` |
| **Untitled UI** | 开源设计系统 | 色彩/圆角/灰阶/阴影/间距令牌，与真实产品 `frontend/src/styles/teacher-ui.css` 的 `--tui-*` 同源 |
| **Ant Design Mobile** | MIT | 交互范式：NavBar / **Cell（本期功能入口直接采用）** / Popup / ActionSheet / Progress / Skeleton |
| **Vant** | MIT | 信息密度参考：Cell 行高、Tabs 下划线、Empty 空态版式 |

> 选型理由：四个项目均为 GitHub 高星（Lucide ~52k、Ant Design Mobile ~12k、Vant ~23k）、稳定的开源成熟项目；组合后既保证「大众审美」的熟悉感，又能通过令牌定制出校园产品自己的性格。

## 2. 风格与美学（v2 重定义）

- style: **neutral-first** · campus-calm
- aesthetic: 「一张安静的今日清单 / 一份打印出来的日程」——**页面本身就是白纸，只有列表容器是卡片**；靠**排版层级 + 留白分节**建立重点，不靠色块。
- tone: calm / restrained / 可信

### 2.1 v2 三条硬规矩（替代 v1）

1. **页面不铺色。** 彩色只允许出现在三类位置：① 2px 竖条（课表分类）；② 小面积文字/数字（截止时间、低分）；③ 极小的状态标签。任何面积超过 200×40px 的色块都算违规。
2. **强调色全局只有一个。** `--accent` 深蓝 `#1a4fd6`，且只用于「可交互 / 当前」的极小面积（进行中标签、选中下划线）。不用于装饰、不用于标题、不用于进度条填充。
3. **功能入口用 Cell，不用 Icon Grid。** 六个快捷入口做成两列单色列表（Ant Design Mobile `Cell` 范式），不是六宫格彩色方块。图标 16px、灰、只用线性描边，靠文字承担信息。

### 2.2 卡片的使用边界

- ✅ 卡片只用于**列表/数据容器**（今日课程、要交的、成长、更多入口）。
- ❌ 卡片不用于**整区包裹**（不再有「Hero 大卡」）。
- ❌ 卡片不做渐变、不做彩色描边、不做大阴影。全站只有一档阴影 `0 1px 2px rgba(20,23,26,.035)`。

## 3. 设计令牌

### 3.1 色彩

**面（三层中性）**

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--bg` | `#f5f6f7` | 页面底 |
| `--surface` | `#ffffff` | 卡片 |
| `--surface-muted` | `#fafbfc` | 卡片内次级底、课块底 |
| `--surface-sunken` | `#eef0f2` | 分段控件槽 |

**文字（四级）**

| 令牌 | 色值 | 对白底对比度 | 用途 |
|---|---|---|---|
| `--text` | `#14171a` | 17.4:1 ✅ | 标题、正文、数字 |
| `--text-2` | `#5b6470` | 6.3:1 ✅ | 次要信息、说明 |
| `--text-3` | `#8b939e` | 3.3:1（仅大字号/非正文） | 辅助标签 |
| `--text-quiet` | `#a8aeb6` | 2.5:1（仅装饰/占位） | 未激活图标、分隔符 |

**线**

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--line` | `#e9ebee` | 列表分隔线 |
| `--line-strong` | `#dcdfe4` | 选中态描边 |
| `--hairline` | `rgba(20,23,26,.055)` | 内描边 |

**强调色（唯一）**

| 令牌 | 色值 | 对比度 | 用途 |
|---|---|---|---|
| `--accent` | `#1a4fd6` | 7.1:1 ✅ | 「进行中」标签、选中指示线 |
| `--accent-soft` | `#eef3fd` | — | 关键词标记笔底色 |

**状态色（只有 2 个）**

| 令牌 | 色值 | 对比度 | 用途 |
|---|---|---|---|
| `--alert` | `#c2410c` | 5.1:1 ✅ | 今晚截止、已逾期、维度低分 |
| `--ok` | `#15803d` | 4.9:1 ✅ | GPA 上升 |

**课表分类色条（仅 2px 竖条）**

| 令牌 | 色值 | 对应课程类型 |
|---|---|---|
| `--bar-1` | `#1a4fd6` | 专业核心 |
| `--bar-2` | `#0f766e` | 学科基础 |
| `--bar-3` | `#b45309` | 公共必修 |
| `--bar-4` | `#6d28d9` | 专业选修 |
| `--bar-5` | `#475569` | 实验 / 通识 |

> 实现要点：色条通过内联 `style="--bar: var(--bar-N)"` + `.tt-course::before` 渲出，**课程块本身是 `#fafbfc` 极淡底**，绝不整块上色。

### 3.2 字体刻度（8px 基线，最多两种字体）

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| Display | 24 / 33 | 600 | 「今天一句话」 |
| Title | 15 / 21 | 600 | 区块标题（今天 / 要交的 / 成长 / 更多） |
| Body-lg | 15.5 / 25 | 400 | AI 洞察导语 |
| Body | 14.5 / 21 | 400 | 列表主行 |
| Metric | 22 / 26 | 700 | 四个数字 |
| Label | 12 / 16 | 400 | 说明、时间 |
| Micro | 10.5 / 14 | 500 | 课块名、脚注 |

字体栈：`"PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", system-ui`；等宽仅用于数字：`ui-monospace, "SF Mono", Consolas`。

### 3.3 间距与圆角

- 间距：`4 / 8 / 12 / 16 / 20 / 24`（8 的倍数为主，4 用于紧贴元素）
- 横向页边距：`--pad-x: 16px`
- 圆角：`--r-xs 6`（课块）· `--r-sm 9`（按钮）· `--r 12`（卡片）· `--r-lg 16`（区块）· `--r-sheet 18`（弹窗）

## 4. 信息架构（v2 未变，但区块语义更口语）

### 主页 5 个区块

| # | 标题 | 内容 | 下钻 |
|---|---|---|---|
| ① | （无标题） | 日期行 + 今天一句话 + 一行 4 个数字 | — |
| ② | 今天 | 下一节摘要 + 竖向时间条（今日课程） | 课程表 |
| ③ | 要交的 | 前 3 条待办 + 完成进度条 | 待办全部 |
| ④ | 成长 | 五维灰条 + 最低项警示 + AI 洞察引用块 | 成长详情 |
| ⑤ | 更多 | 6 个单色两列入口 | 各自路由 |

### 二级页（layer 覆盖式，`.layer.anim-in`）

课程表 / AI 主动发现 / 待办 / 成长详情 / 成绩分析，共 5 页。

## 5. 组件清单与状态

| 组件 | 状态 | 关键规格 |
|---|---|---|
| `.today-line em` | 默认 | 标记笔效果：`linear-gradient(transparent 70%, var(--accent-soft) 70%)` |
| `.metric` | 默认 | 数字 22px/700 + 单位 11px + 标签 11.5px `--text-3`，4 等分 |
| `.next-row` | hover / active | 摘要行，`--accent` 只出现在序号点 |
| `.rail-item` | 进行中 / 常规 | 竖向时间条；`进行中` 用 `.tag-now` 蓝底白字标签（**不只靠颜色**） |
| `.todo-row` | 未完成 / 已勾选 / 逾期 / 紧急 | 勾选圈 20px；完成 = 划线 + `--text-quiet`；逾期 = `.due.is-alert` 赭红字「已逾期」 |
| `.dim-row` | 常规 / 低分 | 灰条 `--text-quiet` 填充；`is-low` 才用 `--alert`，同时数字变赭红 |
| `.fn-cell` | default / active | 两列，`1px solid var(--line)` 分隔，图标 16px `--text-3` + 文字 13.5px `--text` |
| `.insight-block` | 默认 | 引用块：左侧 2px 竖线 + 标签「AI 洞察 · 本月 +1.4」+ 正文 |
| `.tab` | 未选中 / 选中 | 未选中 `--text-quiet`；选中 `--text` 近黑 + 顶部 2px 短线（**不蓝**） |

### 微交互参数

| 动作 | 参数 |
|---|---|
| 按钮 hover | `transform: scale(1.02)`，0.2s |
| 按钮 active | `transform: scale(0.97)`，0.16s |
| 图层进入 | `layer-in` 0.26s `--ease-out`（translateX + opacity） |
| 图层退出 | `layer-out` 0.22s `--ease`（**只加** `pointer-events:none` + transform/opacity，绝不改 position/inset/overflow） |
| 维度条填充 | `width` 过渡 0.5s，逐条延迟 55ms |
| 弹窗 | Popup 上滑 0.28s `--ease-drawer` |
| `prefers-reduced-motion` | 全部退化为即时切换 |

## 6. 无障碍检查清单（WCAG 2.2 AA）

| 项 | 状态 | 说明 |
|---|---|---|
| 正文对比度 ≥ 4.5:1 | ✅ | `--text` 17.4:1、`--text-2` 6.3:1 |
| 大字号/UI 组件 ≥ 3:1 | ✅ | `--alert` 5.1:1、`--accent` 7.1:1 |
| 不只用颜色传达状态 | ✅ | 「进行中」「已逾期」「已完成」均有文字；低分项数字同时变色且列在首条 |
| 语义化 HTML | ✅ | `section / h1 / h2 / ul / li / button`，无 div 冒充按钮 |
| ARIA 补齐 | ✅ | `role="checkbox" aria-checked`（勾选圈）、`role="progressbar" aria-valuenow`（维度条）、`role="tablist"`（分段）、弹窗 `role="dialog" aria-modal` |
| 键盘可操作 | ✅ | 全部交互元素为原生 `button`；Esc 逐层关闭；弹窗打开时焦点落容器（`tabIndex=-1`） |
| 焦点可见 | ✅ | `:focus-visible` 2px `--accent` outline + 2px offset |
| 触摸目标 ≥ 44×44 | ✅ | 勾选圈视觉 20px，热区 44px（padding 补偿） |
| 图标不承载唯一信息 | ✅ | 全部图标 `aria-hidden="true"`，含义由文字承担 |
| 颜色不为唯一标识 | ✅ | 课表图例虽是色条，但课块内**有课程名** |
