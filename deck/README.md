# WisPath CampusMate · 苹果风动画宣传片

> 绵阳城市学院「智慧校园 AI 服务平台」产品宣传 PPT
> 16:9 / 10 页 / 全页原生动画 / 自动连播

- **成品**：`out/WisPath_CampusMate_宣传片.pptx`（PowerPoint 2016+ / WPS / macOS Keynote 可打开）
- **讲稿**：每页备注（演讲者视图可见），共 10 段
- **字体**：中文 微软雅黑 Light / 微软雅黑，英文 Segoe UI（Windows 自带；macOS 打开会回退为苹方/Helvetica，版式不受影响）

---

## 一键重建

```
# Python 3.12 + python-pptx 1.0.2 + Pillow（本机运行时已内置）
python deck/make_assets.py          # 生成 9 张背景 + 20 个图标 + 吉祥物（可复现）
python deck/build_deck.py           # 生成 PPTX（含动画）
# 可选：
python deck/build_deck.py --no-anim # 无动画版本，便于对比
```

素材与文案分离：

| 文件 | 作用 |
| --- | --- |
| `content.py` | 全部中文文案、功能清单、关键数字、讲稿（数据均按代码统计，见 `content_notes.md`） |
| `theme.py` | 苹果风设计系统：配色、字体、玻璃卡片、渐变文字、手机/仪表盘控件 |
| `build_deck.py` | 10 页版式 + 动画编排（每个动画以「绝对时间」登记） |
| `anim.py` | PPTX 原生 <p:timing> / <p:transition> 生成引擎（以 PowerPoint 实际写出的 XML 为蓝本） |
| `make_assets.py` | 背景光晕 / 白色线性图标 / 吉祥物抠图生成器 |
| `render.ps1` / `inspect_anim.ps1` | PowerPoint COM 渲染与动画校验脚本 |

## 10 页叙事与动画设计

| 页 | 内容 | 入场动画（自动播放） | 停留 |
| --- | --- | --- | --- |
| 01 | 问候「你好」 | 品牌字淡入 →「你」「好」逐字放大 → 副标题/标语上浮 → 滚动提示呼吸 | 6.5s |
| 02 | 三个日常问题 | 巨问号 2.6s 缓现 → 三条问题依次上浮（0.55s 节奏）→「如果，一句话就能解决？」自下擦除 → 尾注 | 9s |
| 03 | 产品亮相 · 绵小城 | 窗口缩放浮现 → 四轮对话气泡依次上浮 → 工具调用胶囊 → 输入框 → 打字点呼吸 | 11s |
| 04 | 四种核心能力 | 标题上浮 → 四张玻璃卡错峰上浮 + 图标缩放 → 能力标签 | 10s |
| 05 | 学生端 · 移动端 | 双手机依次上浮 + 光晕 → 聊天气泡 + 成长档案圆环缩放 → 右侧四项能力从右滑入 → 标签 | 12s |
| 06 | 教师端 · 移动端 | 左侧文字 → 手机浮起 → 2×2 KPI 错峰 → 审批卡 →「同意」按钮缩放 + 波纹 → 已同意 toast → 危机预警卡（呼吸） | 12s |
| 07 | 管理端 · 全局 | 窗口缩放 → KPI 数字 → 7 根柱状图自下生长（错峰）→ 健康度圆环 → 功能胶囊 | 12s |
| 08 | 技术底座 | 标题 → 四层架构从右滑入 → 技术胶囊 → 安全条目 → 关键数字 | 10s |
| 09 | 功能全景 | 标题 → 三列卡片错峰上浮 | 11s |
| 10 | 总结 | 「让校园服务，从一句话开始」两行擦除 → 四个价值词 → CTA → 品牌落版 | 结束（不自动换页） |

- 全部动画为「上一动画之后 / 与上一动画同时」触发，**放映即自动播放**，无需点击；配合每页自动换片时间，可整场无人值守连播。
- 切换统一为 Apple 式慢速交叉淡化（<p:fade/>，1.0~1.4s）。
- 若想手动控制节奏：PowerPoint「切换 → 计时 → 取消勾选『设置自动换片时间』」，动画仍会自动播，只是不再自动翻页。

## 已验证（PowerPoint 16 COM 实测）

- 10 页全部打开无修复；`Slides.Count = 10`
- 每页动画数量：7 / 13 / 21 / 23 / 29 / 44 / 25 / 31 / 7 / 8（合计 218）
- 所有效果的 `TriggerType` 仅 2（与上一动画同时）/ 3（上一动画之后），**无 1（单击触发）**
- 每页 `SlideShowTransition.EntryEffect = 3849`（平滑淡出），`AdvanceOnTime = true`，`AdvanceTime` 与设计值一致
- 讲稿备注 10 段均已写入
